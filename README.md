## Deploy on GitHub Pages (free)

1. On GitHub, create a new repository — name it `your-username.github.io` if you want it at the root of your GitHub domain, or anything else (e.g. `portfolio`) if you're fine with a `/portfolio` path.
2. Upload `index.html` and `resume.pdf` to the repo (drag-and-drop via "Add file → Upload files" works, or use git).
3. Go to **Settings → Pages**, set **Source** to "Deploy from a branch", branch `main`, folder `/root`. Save.
4. Wait 1–2 minutes, then visit the URL GitHub gives you (shown on that same Settings → Pages screen).
